# Veyra Studio

Node-based compositing, editorial and review studio written in plain JavaScript with a modular WebGPU renderer.

This repository is being populated from the complete Veyra Studio source archive. The browser application, reusable core/renderer/control packages, server API, SQLite launcher, tests and documentation are included in the source import.

The GitHub Pages build will run in browser-local mode; server-backed multi-user collaboration requires the included backend.
